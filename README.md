# Task 2 – Phishing Email Analysis

## Objective
To identify phishing characteristics in a suspicious email sample.

## Email Details
Subject: URGENT: Action Required – Your Microsoft 365 Account Will Be Suspended Today

From: security-update@microsooft-security-alerts.com

Reply-To: support@microsooft-security-alerts.com

## Phishing Indicators Found

1. Typosquatting sender domain
2. Suspicious Reply-To address
3. Microsoft impersonation
4. Urgent and threatening language
5. 24-hour verification deadline
6. Suspicious verification URL
7. Possible credential harvesting attempt

## Suspicious URL
http://com-verify-user.net

## Conclusion
The email is highly likely to be a phishing email because it impersonates Microsoft, uses a suspicious domain, creates urgency, threatens account suspension, and directs the user to a suspicious verification website.
